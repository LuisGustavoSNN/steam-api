## Sobre o projeto

O Steam API é um projeto desenvolvido com foco na integração
com a plataforma Steam, explorando a comunicação entre
sistemas e o consumo de APIs externas.

O projeto tem como objetivo aprimorar conhecimentos em
desenvolvimento back-end, organização de código e integração
com serviços externos.

## Objetivos

- Integração com a Steam API.
- Consumo de APIs externas.
- Manipulação de dados.
- Utilização de requisições HTTP.
- Aplicação de boas práticas de programação.
- Organização e manutenção do código.

## Instalação

Clone o repositório:

```bash
git clone https://github.com/LuisGustavoSNN/steam-api.git
```

Acesse o diretório da aplicação:

```bash
cd steam-api/Steam
```

Configure o ambiente e instale as dependências necessárias
de acordo com os arquivos do projeto.

## Steam Web API

Caso a aplicação necessite de uma chave de acesso à
Steam Web API, ela pode ser obtida através do endereço:

https://steamcommunity.com/dev/apikey

Por questões de segurança, recomenda-se não armazenar
chaves de acesso diretamente no código-fonte.
